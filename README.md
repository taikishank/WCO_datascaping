We will be using this to create our own API endpoints for webscraping the following information
As far as I'm aware, there's no single website that contains all of this information.
Therefore, we will have to scrape multiple websites for this to work.

Offensive Efficiency (Points Per Possession)
Defensive Efficiency (Points Allowed Per Possession)
Pace (Possessions Per Game)
Effective Field Goal Percentage (eFG%)
Adjusted FG% that accounts for 3-pointers being worth more than 2-pointers.
Turnover Percentage (TO%)
Offensive & Defensive Rebound Percentage (OREB% / DREB%)
Free Throw Attempt Rate (FTA/FGA)
Assist-to-Turnover Ratio
Three-Point Attempt Rate (3PA/FGA)
How reliant a team is on the 3-point shot.
Opponent Shot Distribution
% of shots taken at the rim, midrange, and from three.
Player-Level Stats:
Usage Rate (USG%)
How much of the offense a player controls.
Offensive and Defensive Rating (ORTG / DRTG)
Assist Percentage (AST%)
Turnover Rate (TOV%)
On/Off Court Impact (+/-)
